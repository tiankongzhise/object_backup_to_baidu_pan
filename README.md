# object_backup_to_baidu_pan
本程序预期开发一个备份系统，用于将本地文件和文件夹加密打包后备份到百度网盘。
本地文件与和文件夹由用户指定。将文件夹下的一级子文件和文件夹加密打包。压缩包不需要再次压缩。
对于已经备份过的文件，不再重复备份。
由于本程序可能运行在多台电脑上，需要比较本地文件和数据库中的文件列表，和文件的hash值。以确定哪些文件需要备份。
备份完成后删除源文件和压缩包。已经备份过的文件直接删除。
需要备份的文件和文件夹大小需要小于20G.进行特殊标准，需要人工处理。
对于一级子文件夹，如果其下文件数量(不计子文件夹)超过200个。进行特殊标注，需要人工处理。
hash值需要计算md5,sha1,sha256三种，三种一致算同一文件。
备份压缩的文件也需要计算hash值，并记录到数据库。避免被重复计算。
备份压缩的文件，需要进行解压验证，计算解压出来的文件或者文件夹与源文件或者文件夹的hash一致，保证压缩的正确性。
支持断点续传和失败重试
资源使用可控，避免磁盘空间不足
提供监控和日志便于问题排查
